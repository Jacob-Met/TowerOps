## Cold replay and layout

Keep every file in this directory unchanged. native-peer.tar.xz contains 382 ordinary relative members without a top-level wrapper. native-manifest.json binds each member's bytes, SHA-256, Git blob and projection mode; archive-freeze.json binds the archive. receipt.json binds the complete exposed packet.

Run:

    python3 -B verify-peer.py .
    python3 -B -O verify-peer.py .
    python3 -B verify-peer.py . --negative-controls

The standard-library verifier reads archives and saved observations only. It does not import or execute the product, start a browser, access a service, or reconstruct a new planner result. It independently recomputes all displayed values from captured native JSON, original JSON equality, exact downloads, source closure and current README reconstruction. Its separate cold negative controls change an observed admitted count and saved download bytes in memory, and require rejection at the intended semantic boundaries.

Historical native paths in commands and reports are provenance. Replay uses archive-relative paths and does not require those paths to exist. The complete author packet is separate and is not silently substituted for independent evidence.
