# Additional Explorer release installer — source and receiving

This additive publication introduces `tools/stage_explorer.py`, its focused tests and `docs/EXPLORER_RELEASES.md`. It uses the unchanged maintained `tools/install_explorer.py` filesystem helpers. Existing Explorer runtime, default selector, older releases, README and workflows are preserved. The installer stages an explicitly supplied eight-file saved composition under a full content digest, then creates a new version-specific foreground command. Content identity is not source or runtime qualification.

Start with the maintained [release guide](../../EXPLORER_RELEASES.md). Use `inspect` to view an independently admitted content manifest, then supply the reviewed digest explicitly to `install`. Collisions and repeated installations refuse without replacement. Late write/readback/synchronization/receipt/console failures can retain partial or usable new state; inspect the recorded state before choosing another reviewed release. The utility never starts Explorer or changes the default `towerops-explorer` command.
