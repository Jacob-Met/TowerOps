## Retention and replay boundary

The criteria, builder, receiver, original manifests/oracles, external freeze, later candidate admission, exact launch record, full raw receipt and streams are retained. The source A/B payloads are included as input fixtures. Product utility/helper bodies remain in their maintained source locations; they are not reclassified as independent evidence.

The receiver and fixture builder record their original absolute owned paths. The already-used receiver deliberately refuses a second run at its occupied output path. Direct replay requires a fresh isolated stage, explicit path adaptation and a newly recorded freeze/admission; this publication does not claim that an extracted or renamed copy was executed. It does not cover native PATH adoption, Explorer runtime behavior, race-resistant security against the same account, power-loss durability, all size/admission limits, or injected write/fsync/console failures. Those remain separate source/author/adoption boundaries. Root will receive the separately published issue138 composition before any real side-by-side adoption.
