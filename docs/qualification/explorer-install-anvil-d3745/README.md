## Use the adopted command

After the actual adoption recorded in [independent/README.md](independent/README.md), use:

```sh
towerops-explorer --port 8765
```

Open the printed loopback address. Choose an unused port; `--port 0` asks the server to allocate one. Ctrl+C stops this foreground server. Installation does not launch a browser or server, register a service or schedule anything.
